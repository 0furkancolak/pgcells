# Design history

Specs and plans written while building pgcells. They are kept as the record of why things are the way they are; the user-facing documentation lives in `packages/*/docs` and `docs/guides`. Most documents are in Turkish and are not translated.

> **Naming (2026-10-19):** the documents below say `@pgcells/multi`, `@pgcells/single` and `@pgcells/redis`. The packages are published as `@0furkancolak/pgcells`, `@0furkancolak/pgcells-single` and `@0furkancolak/pgcells-redis` (no GitHub organization; the repository is `0furkancolak/pgcells`).
